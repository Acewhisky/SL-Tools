# 游戏存档管理工具

本地游戏存档手动备份工具，支持一键备份 / 一键恢复（S/L）、版本管理、哈希校验、定时与变化监听自动备份。完全离线运行，不依赖任何云端服务。

当前版本：**v2.0.1**（版本号见 `backend/version.py`，单一来源）

## 版本号规则（自 2.0.1 起执行）

| 位 | 含义 | 示例 |
|----|------|------|
| 第三位（patch） | Bug 修复 / 小改动 | `2.0.1` |
| 第二位（minor） | 新功能 / 大更新 | `2.1.0` |
| 第一位（major） | 破坏性变更 / 里程碑 | `3.0.0` |

> 规则：每次代码提交（以 commit 为准）均需更新版本号。小修复更新第三位数字，大更新更新第二位数字。

## 快速开始

### 1. 启动

双击 `start.bat`（首次运行会自动创建 Python 虚拟环境并安装依赖），或手动执行：

```bash
python app.py
```

启动后自动打开浏览器访问 `http://127.0.0.1:8765`，界面如下：

- **左侧**：游戏列表（支持关键词搜索、平台筛选）
- **右侧**：当前游戏的存档路径、备份目录、备份历史时间线

### 2. 首次使用

1. 点击顶栏「🔍 扫描游戏」——自动识别本机已安装且有存档的游戏（内置 150+ 主流游戏规则；**联网时自动下载 Ludusavi 规则库（19000+ 游戏）增强识别范围**，离线自动降级为内置规则）
2. 点击游戏 → 「💾 立即备份」创建第一个备份
3. 之后每次想 S/L：选择版本 → 「↩️ 一键恢复」

### 3. 手动添加游戏

点击左下角「＋ 手动添加游戏」，填写游戏名称、存档路径（支持 `%APPDATA%`、`%LOCALAPPDATA%`、`%DOCUMENTS%`、`%SAVED_GAMES%` 等变量）、运行进程名。

## 功能总览

| 功能 | 说明 |
|------|------|
| 游戏扫描识别 | 内置 150+ 主流游戏规则；联网自动更新 **Ludusavi 规则库（19000+ 游戏）** 增强识别（可在设置中关闭） |
| 隐藏游戏 | 列表项 hover 显示 ✕ 可隐藏，设置页可恢复显示；隐藏的游戏不参与批量备份 |
| 一键备份 | 备份到可配置目录，目录名 = 时间戳，逐文件计算 SHA256 |
| 一键恢复 | 选择备份版本覆盖当前存档；**恢复前自动备份当前存档**，游戏运行中拒绝执行，失败自动回滚 |
| 版本管理 | 保留最近 N 个版本（N 可配置），超限自动清理；**收藏的版本永不清理** |
| 哈希校验 | 对任意版本重新计算 SHA256 与备份清单比对；校验失败标记「异常」并保留待手动处理 |
| 压缩存储 | 可选 ZIP / TAR.GZ 压缩备份 |
| 自动任务 | 定时备份（小时/天/周）+ 存档目录变化监听自动备份（防抖） |
| 搜索筛选 | 游戏列表关键词搜索 + 平台筛选 |
| 二次确认 | 恢复、删除、清理等危险操作前弹窗确认 |
| 配置导入导出 | 游戏列表与设置可导出/导入，便于迁移电脑 |
| 运行日志 | 顶栏「📋 日志」查看操作记录与错误 |

## 数据存储

所有数据在项目 `data/` 目录下，均为 JSON 格式，可直接用文本编辑器修改：

```
data/
├── settings.json      # 全局设置（备份目录、保留数量、压缩格式、自动任务）
├── games.json         # 游戏列表（内置识别 + 手动添加）
├── backups/           # 备份存档（每个游戏一个子目录，每版本一个时间戳目录）
│   └── <游戏ID>/
│       └── 20260808_190000/
│           ├── manifest.json   # 文件清单 + SHA256 哈希
│           ├── meta.json       # 版本元信息
│           └── data/           # 实际存档文件（未压缩时）
└── app.log            # 运行日志
```

## 配置说明（settings.json）

| 键 | 说明 | 默认值 |
|----|------|--------|
| `backup_root` | 备份存档根目录（可手动配置） | `data/backups` |
| `keep_versions` | 保留最近 N 个版本 | `5` |
| `compress_format` | 压缩格式：`none` / `zip` / `tar.gz` | `none` |
| `watch_auto_backup` | 全局开关：存档变化自动备份 | `true` |
| `watch_delay` | 变化后延迟备份秒数（防抖） | `8` |
| `auto_open_browser` | 启动时自动打开浏览器 | `true` |
| `auto_tasks` | 定时任务列表（在前端「设置」中管理） | `[]` |

## 技术栈

- 后端：Python 3.13 + Flask + waitress（Windows 下稳定服务）
- 进程检测：psutil（恢复前检测游戏是否运行）
- 文件监听：watchdog（存档变化自动备份）
- 前端：原生 HTML5 + CSS3 + JavaScript（无框架，离线可用）

## 注意事项

- **Steam 云存档冲突**：若开启 Steam 云同步，恢复本地存档后 Steam 可能用云端旧版覆盖，恢复前建议在 Steam 中暂停该游戏的云同步。
- **UAC 权限**：若存档位于受保护的系统目录，备份/恢复可能提示权限不足，建议以管理员身份运行 `start.bat`。
- 备份目录与游戏存档路径**不要**设置在同一个目录，避免备份自身被纳入监听/复制。
